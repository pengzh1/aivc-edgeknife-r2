# wsD：MLP 架构与超参冲刺 + 多种子集成

代码：`src/wsD_arch.py`（独立模块，复用 `src/train_mlp.py` 的 Encoder/masked_mse 与 `src/evaluate.py` 的 Harness，未修改任何已有文件）。
数据合规：仅用 `h.tr_rows` 训练；val 划分只用于评分；未触碰 `h.Y_te`；所有种子固定。

## 结果摘要

| 模型 | composite |
|---|---|
| 基线 MLP 单种子（512→1024，emb_drop 0.25，100 ep） | 0.470（复现 0.4696） |
| 本工作最佳单模（单种子均值，8 种子 0.5015–0.5301） | **0.5222 ± 0.0086** |
| 本工作 8 种子均值集成（`pred_trainval.npy`） | **0.5381** |
| 参照：3 种子 MLP + Ridge 0.8/0.2 集成 | 0.509 |

单模已稳定超过 0.50 目标（8 种子中 7 个 ≥ 0.519），集成后 +0.016。

## 最佳配置

```
hidden = (1024, 2048, 2048, 2048, 2048)   # 5 层，GELU + LayerNorm
loss = Huber(smooth_l1, beta=1.0，masked)
epochs = 300（cosine schedule）, lr = 1e-3, weight_decay = 1e-4
batch = 256, dropout = 0.3, emb_drop（菌株/化合物→UNK）= 0.35
化合物嵌入 32 维（其余同基线），无残差/低秩头/FiLM
集成：种子 0–7 共 8 个模型，预测取算术均值
```

## 过拟合观察（最佳配置，种子 0，标准化空间 masked 损失）

| epoch | train loss | val masked-MSE |
|---|---|---|
| 10 | 0.1163 | 0.3375 |
| 40 | 0.0896 | 0.2865 |
| 100 | 0.0807 | 0.2775 |
| 150 | 0.0774 | 0.2827 |
| 200 | 0.0745 | 0.2924 |
| 250 | 0.0725 | 0.2886 |
| 300 | 0.0715 | 0.2888 |

train loss 全程单调下降（0.116→0.072）；val MSE 在 ~40–100 epoch 见底（≈0.277–0.287）后轻微回升并走平。存在温和过拟合，但在 dropout 0.3 + emb_drop 0.35 + cosine 衰减下被压平——val MSE 从 100→300 epoch 仅回升约 0.01，而 composite 仍随训练延长小幅上升（0.5186@100ep → 0.5245@300ep，2 种子口径）。无增强正则会合的 5 层网延长训练则 composite 下降（0.5143→0.5117），说明收益来自"强正则 + 长训练"的组合而非训练长度本身。

## 与 0.470 基线的差异分析

提升来源分解（单模口径，基线 0.470 → 0.523）：
1. **深度 2→5 层（+0.040）**：最大单项。扰动响应是条件间高阶交互，浅网欠拟合；但同维残差与 FiLM 反而有害（破坏 LayerNorm 尺度/门控过强），纯前馈深网最优。
2. **强正则 + 长训练（+0.007~0.010）**：dropout 0.1→0.3、emb_drop 0.25→0.35、100→300 ep。emb_drop 强迫学习未见菌株/化合物的 UNK 回退表示，直接服务 OOD 划分。
3. **Huber loss（+0.002）**：对极端丰度变化样本更稳健。
4. **8 种子集成（+0.016）**：种子方差大（单模 0.5015–0.5301），均值集成稳定获利。

分划分看（基线单种子 → 集成）：chem_only FC 0.404→0.508、resid 0.363→0.487；strain_only FC 0.248→0.331、resid 0.250→0.336；both FC 0.164→0.218；time FC 0.591→0.640。OOD 的 FC/残差指标提升幅度远大于保真度（fidelity 已接近饱和 0.92–0.96），说明增益主要来自对未见化合物/菌株响应模式的泛化，而非对训练分布的更好拟合。strain_only 与 both 仍是短板（FC 0.33/0.22），未见菌株的响应建模提升空间最大。
