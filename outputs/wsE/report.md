## 方法与网格结果

1. ŷ_ens = 0.8·MLP(3seed)+0.2·Ridge（基线 0.5091 复现确认）；control_hat = train 对照 7 键分组均值 + 分层回退（7k 命中 7122 行；val_strain_only/val_both 的处理行 **100% 无 7 键/4 键命中**，回退 3 键）。
2. train（n=5078 处理样本，未校准 F1=0.3476）：全局 γ*=1.45→F1 0.4632（平台 1.35–1.50）；分方向 1.40/1.55→0.4652；噪声加权→0.4576；7 键门控硬门 a=0.7 γ=1.5→0.4629；band a=0.5 γ=1.3/1.5→0.4312/0.4495（副作用代理 dmg 最低 0.006/0.017）。
3. val 候选总表（composite / DEP_F1 均值）：全局 γ=1.45（train 最优）0.4817 / 0.2136；分方向 0.4794 / 0.2126；噪声加权 0.4790 / 0.2077；γ=1.20 0.4996 / 0.2113；7 键门控 γ1.3 0.5083 / 0.2124；7 键硬门 γ1.5 0.5051 / 0.2258；**band γ1.3 0.5094 / 0.2141**；band γ1.5 0.5085 / 0.2205。

## 权衡要点

- 裸膨胀失败两因：① `ŷ_cal = control_hat + γΔ̂` 把锚点误差也放大 γ 倍，回退行（strain/both 全部）fidelity/FC/resid/dir_acc 全面恶化；② 全条目加噪使 chem resid_PCC −0.04（20% 权重，−0.008 composite），远超 DEP 收益（+0.003）。
- 两道闸门对症：**7 键可靠性门**（无可靠锚点的行不动）+ **梯形带门**（只把 |Δ̂|∈[0.5,1) 的边际条目推过阈值，≥1 的条目不动；映射单调不翻号 → dir_acc 不变、he_PCC ≈不变）。仅 6.87% 条目被修改，最大改动 0.30 log2。
- "γΔ 不动 FC_PCC"成立条件是纯 per-sample 缩放；实际含锚点偏差且带门逐条目变化，故 FC/resid 有 ≤0.004 的小幅变化，已实测上报。
- F1≥0.25 不可达：strain/both 两划分占均值一半，其 OOD 设计（train 无对应菌株对照）决定诚实锚点无法安全校准；天花板 ≈0.226。

## test 迁移

对 test 元数据用同一 train 冻结对照表算 control_hat 与命中层级，仅对 7 键精确命中的 test 处理行施加同一带门（a=0.5, γ=1.3）。预期 chem/time 类行 F1 +0.04~0.07，strain/both 类行自动不受影响、零损失。备选：band γ=1.5（F1 0.2205, composite −0.0006），若官方 DEP 权重高于本地近似可考虑，默认仍推荐 γ=1.3 版。
