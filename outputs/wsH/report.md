# wsH 分样本角色集成路由报告

## 方法

- 封闭候选：wsD / wsB / wsC / 旧MLP / Ridge；开放另加 wsA。
- 每个 val 划分内部独立搜索混合权重：顶点 + 200 Dirichlet(1) + 100 Dirichlet(0.3)（种子固定 20260806），目标 = 0.45×FC_PCC + 0.45×resid_PCC(有则) + 0.10×fidelity（近似口径，与 score_fast 相同的向量化实现，真值侧统计预计算）。
- 防过拟合收缩：w_final = r × 划分最优 + (1−r) × 全局最优（全局 = wsD .70 / wsB .266 / wsC .019 / MLP .015 / Ridge 0，开放版 wsA=0）；train split 样本一律用全局权重。
- 最终混合用 `h.score_val` 完整评分（唯一公允口径）。

全局权重基线（同一 val 上完整评分复核）：composite = **0.5413**（与既有日志 0.5413 一致）。

## 过拟合诚实讨论

- 权重在每个 val 划分内部调过、又在同一 val 上评分，上表 composite **存在 in-sample 乐观**；划分越小（both n=269、time n=157）乐观越大。
- 缓解手段：0.5 收缩（交付档）把划分最优与全局最优各取一半；全局权重本身也是在同一 val 上调的，但自由度只有 k−1，而路由额外引入 4×(k−1) 个自由度，乐观增量主要来自小划分。
- 因此 test 上的真实增益应预期**小于**本地 Δ；若收缩扫描中 r=0.5 与 r=0.3 差距很小，说明路由增益稳健部分有限，主打 chem/strain 两个大划分。
- r=1.0（不收缩）只作对照展示过拟合上界，不作为交付。

### 交付档位为何取 r=0.5 而非 in-sample 最高的 r=0.7

r=0.7 与 r=0.5 的完整 composite 只差 +0.0009（封闭）/ +0.0010（开放），远小于划分内搜索本身的 in-sample 噪声（both/time 划分 n=269/157，305 个候选点取最优可轻易制造 ±0.002 的虚假增益）。r 越大在小划分上吃进的过拟合越多（both 最优竟给 Ridge 0.35–0.44 的权重，明显是小样本伪信号）；r=0.5 是任务规定的先验中点，对大小划分都保留了足够的正则。r=0.3 与 r=0.5 差距（−0.0013/−0.0015）同样很小，说明路由增益中稳健的部分主要来自 chem/strain 两个大划分的权重倾斜。

### 其他观察

- 划分最优权重的结构与各模型族特长一致：strain 侧 wsB 主导（0.77–0.80），chem/time 侧 wsD 主导（0.72–0.84），time 侧 wsC 稳定获得 0.14 左右——路由确实按预期方式分配权重。
- 开放榜搜索只在 val_chem_only 给 wsA 显著权重（0.137，chem FC 0.5101→0.5122、resid 0.4880→0.4904），其余划分 wsA≤0.018，与"wsA 仅对 chem_role 非 train 样本有意义"的预期完全一致。
- 代价：chem 划分 DEP_F1 略降（0.2099→0.2031，r=0.5），因 wsB/Ridge 混入摊薄了高效应端信号；DEP 权重仅 5%，不改变结论。

## test 映射规则推荐

train_val 中角色与划分严格对应：val_chem_only=(strain train, chem val)、val_strain_only=(strain val, chem train)、val_both=(双 val)、val_time=(双 train，时间/批次外推)。模型只在 train split 上训练，因此 val 角色对模型而言与 test 角色同为'未见'。推荐规则：

- chemical_role≠train 且 strain_role=train → chem_only 权重（test 中 1640 例）
- strain_role≠train 且 chemical_role=train → strain_only 权重（1534 例）
- 双角色均≠train（含 test/test 425、val/test 432、test/val 272）→ both 权重
- 双角色均=train（151 例，与 val_time 同构的时间/批次外推）→ time 权重（保守起见也可用全局权重，二者差异很小）

即任务提议的映射（chem=test→chem_only、strain=test→strain_only、双test→both）方向正确，补充两点：role=val 应与 test 同等视为'未见'；双 train 样本按 val_time 同构处理。
