# CGD/CRD 近克隆菌株对：变异级机制分析报告

**项目**：虚拟酵母细胞竞赛（复赛，机理叙事/特别奖方向）
**目的**：为最终管线中 CRD←CGD β 有界迁移（`src/wsN8_crdtransfer.py`，β=0.35，代码默认 0.25）提供机制层面的叙事支撑——定位两株基因型差异，与竞赛数据内可合法计算的响应差异交叉，回答"哪些基因/通路的差异可能解释两株响应不同"。
**声明**：本分析**仅叙事**，不改模型、不改任何校准参数、未入模。训练侧统计只用 train split；**Y_te 零接触**；不联网、不装新包。所有产出在本目录（`analysis/crd_variants/`）。

---

## 1. 执行摘要

- CGD 与 CRD 是 1011 酵母基因组计划的近克隆对（官方 SNP 距离 0.383–0.398%，本分析在"两株基因型均被呼叫的位点"口径下复核为 0.155%，口径差异见 §3.2）。对 5.83GB 群体 gVCF 做流式扫描（175.5 万变异行，未落盘解压），两株在 **24,594 个位点基因型不一致**，其中高置信纯合差异 20,389 个：**错义 4,649、同义 7,067、启动子区 4,526、终止区 1,653、移码 166、提前终止 25**，涉及 **4,492 个基因**。
- 拷贝数层面差异更尖锐：**CRD 携带 ARR1/ARR2/ARR3 砷抗性基因簇 ~2.5× 扩增（CGD 单拷贝）**，与 1011 表型矩阵中 CRD 对亚砷酸钠 4.5× 的生长优势定量自洽；**CGD 丢失/深度趋异 277 个参考 ORF（含 QDR3、PDR11、SNQ2、QDR1、HXT1、SIT1、MSN2 区、UTH1、STL1、IRC7、MIH1），CRD 仅硬缺失 12 个**（含 SEO1、BDS1、MAL 座）。
- 功能分布高度非随机地集中于**膜转运/药物外排（PDR）、细胞壁完整性、渗透与离子稳态、糖转运**——正是"化合物扰动响应"的上游决定层。1011 表型矩阵独立证实：CRD 对咖啡因（3×）、环己酰亚胺（2×）、制霉菌素（3.7×）显著更敏感，对高温（2.1×）与砷（4.5×）显著更抗。
- 响应侧关键事实：**CRD 不在 train_val 数据中（仅存在于 test split）**，因此"同化合物同上下文 CGD vs CRD 的 Δ_true 差异"在不触 Y_te 的红线下**不可计算**。本报告以两层合法代理替代：CGD 自身响应活跃谱（1,553 处理行 × 43 化合物）与"菌株背景敏感性"（969 个化合物×上下文组内 CGD vs 其余 4 株的中位差，|差|中位 0.17 log2、q90 0.61、q99 1.51）。
- 机制结论：两株的响应差异预期是**分布式、通路级、中等量级**的——与"迁移 CGD 的菌株特异调制 m 并乘以 β=0.25–0.35 收缩"的设计自洽：化合物主效应共享，菌株特异的 PDR/细胞壁/离子稳态差异由 β 小幅吸收。差异并非单基因大效应，不支持逐基因大幅改写。

## 3. CGD/CRD 序列差异全景

### 3.1 总量与分类

- 群体 gVCF 共 1,754,866 个变异行；两株均被呼叫 1,659,041 个位点，**不一致 24,594（1.48%）**。
- 基因型构成：纯合差异（0/0 vs 1/1）21,709；杂合涉及 2,885（两株杂合率均 <0.1%，近于完全纯合的二倍体/单倍体背景）。
- 类型：SNP 18,958、indel 1,219、多等位 4,417。
- 高置信集（纯合差异 + 双株 DP≥4、GQ≥20）：**20,389 位点**，注释分类：

| 类别 | 数量 | | 类别 | 数量 |
|---|---|---|---|---|
| 同义 | 7,067 | | 终止区 | 1,653 |
| **错义** | **4,649** | | 基因间区 | 1,188 |
| **启动子** | **4,526** | | inframe indel | 942 |
| nc/内含子 | 172 | | **移码** | **166** |
| **提前终止** | **25** | | 终止子丢失 | 1 |

- 涉及基因 4,492 个（全注释基因 6,459 中的 70%）——近克隆对的差异**散布全基因组**，非局部斑块。染色体分布均匀（170–310 差异位点/100kb，chr5/chr6 密度最高），见 `fig_variant_landscape.png`。
- 方向性：错义中 CGD 携带非参考等位 2,906 vs CRD 1,743——CGD 相对 S288C 参考趋异更远。

### 3.2 与官方 0.398% 的口径差异（诚实说明）

本分析在"双株均被呼叫的双等位 SNP 位点"上加权（纯合 1.0/杂合 0.5）得 18,701 个差异碱基，占全基因组 12,071,326bp 的 **0.155%**；官方 `1011DistanceMatrixBasedOnSNPs.tab.gz` 为 CGD→CRD 0.398%、CRD→CGD 0.383%（双向不对称说明分母各异）。差异 2.6× 的可能来源：官方基于 de novo 组装比对且分母为两株各自的可比区域、并计入 indel 与多等位差异；本口径只计群体变异矩阵中两株均有基因型的位点、分母为全基因组。两者同量级，均支持"近克隆对（<0.5%）"的定性结论；本报告下游分析（注释、交叉）全部基于本口径的可溯源位点集。

### 3.3 存在/缺失与拷贝数：比 SNP 更尖锐的差异层

`genesMatrix_CopyNumber.tab.gz`（7,796 pangenome ORF）：

- **CRD 硬缺失 12 个参考 ORF**（CGD 保有）：SEO1（2 拷贝）、BDS1/YOL162-164W PAU 簇（2 拷贝）、MAL 座（YGR288W/289C）、YLR157C/161W（5 拷贝）等，多为亚端粒多态基因座。gVCF 二扫验证：这些区 CRD 的 call 率仅 **16.6%**（全基因组 98.1%），几乎无 reads 比对——**真缺失**。
- **CGD 丢失/趋异 277 个参考 ORF**（CRD 保有），呈 ~25 个长区块分布（YBR007-078、YCR099-107、YDL007-051、YDR006-059、YDR518-541、YER059-076、YFL008-033、YGL019-054、YHR091-098、YIL010-014、YJL165-171、YJR129-159、YLR078-130、YML082-086、YMR030-041、YOR378-394、YPL030-032、YPR144-155 等）。gVCF 二扫：这些区 CGD 的 call 率 **71.5%**（全基因组 95.9%），被叫位点中 8.9% 为纯合非参考（全基因组均值 3.2%）——reads 大部分可比但质量差、序列趋异，混合了"真缺失、组装缺口、深度趋异"三种情形。**措辞上记为"参考型 ORF 在 CGD 中缺失或深度趋异"**，置信度弱于 CRD 的 12 个硬缺失。功能上仍意味着这些基因产物的参考型功能在 CGD 中不可假定。
- 关键个案（拷贝数 CGD/CRD）：**ARR1/2/3 = 1.0/2.5**；QDR3 = 0/1；PDR11 = 0/1；SNQ2 = 0/1；QDR1 = 0/1；HXT1 = 0/0.5；SIT1 = 0/1；UTH1 = 0/0.5；MSN2（YMR037C）= 0/1；STL1 = 0/1；IRC7 = 0/1；MIH1 = 0/1；ADH7 = 0/2.0；RDS1 = 0/2.5；FLO9 = 0/2.5；SEO1 = 2.0/0；BDS1 = 2.0/0。
- rDNA 大簇拷贝数：RDN58 112.5 vs 82.5、RDN25 98 vs 70.5、RDN18 101 vs 77.5（CGD 多 ~30%）——核糖体生物发生与全局蛋白丰度基线的潜在差异源。
- 注意：CN=0 与"gVCF 密集 1/1 差异"共存（如 QDR3 区内 56 个 HQ 差异位点）是旁系 reads 比对/序列趋异的典型表现，两证据互洽而非矛盾。

### 3.4 表型独立佐证（1011 phenoMatrix，35 条件生长比）

`fig_phenotype.png`。CRD 相对 CGD：**更敏感**——咖啡因 0.068/0.204（3×）、环己酰亚胺 CHX1 0.125/0.261（2.1×）、制霉菌素 0.061/0.224（3.7×）、羟基脲 0.274/0.412、乙醇/甘油/乙酸/山梨醇碳源普遍偏差；**更抗**——亚砷酸钠 0.411/0.090（4.5×）、42°C 0.573/0.270（2.1×）、NaCl 1.5M 0.294/0.190、SDS 0.329/0.186。即：尽管 SNP 距离仅 ~0.2-0.4%，两株在**化合物与胁迫生理上系统性不同**——菌株特异调制不是噪声，是有生理实体的信号。

## 4. 响应侧（竞赛数据，Y_tr only）

### 4.1 重要发现：CRD 不在 train_val

train_val 元数据（8,958 行）的菌株列为 BAH/BAI/CEK/CGD/DHY210 五株，**无 CRD**（CGD：train 1,465 + val_chem_only 261 + val_time 36）。CRD 仅存在于 test split。因此在 Y_te 零接触红线下，任务书预设的"同化合物同上下文 CGD vs CRD 的 Δ_true 直接对比"**不可计算**——这不是样本量小的问题，是零覆盖。以下为两层合法代理。

### 4.2 代理 A：CGD 响应活跃谱

CGD 处理行 1,553（43 个化合物）。每蛋白跨化合物统计（`cgd_response_profile.csv`）：响应强度（mean|Δ|）前 10% 阈值 0.44 log2；HPF1（1.78）、IRC7（1.26）、MIH1（1.16）、ZRT3（0.94）、GRE1（0.90）、GAS3（0.86）等最强。

### 4.3 代理 B：菌株背景敏感性（CGD vs 其余 4 株）

969 个（化合物×Medium×Temperature×pert_time）组同时含 CGD 与至少一株其他菌，逐蛋白中位差共 357 万条（`strain_sensitivity_pairs.csv`）。**菌株背景效应量级：|中位差| 中位 0.174 log2，q90=0.610，q99=1.515**。每蛋白汇总（`sens_absmedian_diff`，敏感性前 10% 阈值 0.37）高者：HPF1（1.31）、BDS1（1.13）、UBC5（1.12）、IRC7（0.93）、NCW2（0.77）、ZRT3（0.70）、ROM1（0.65）、ADH7（0.62）。
解读：同一化合物同一上下文下，菌株身份本身就能移动蛋白响应 ~0.2-0.6 log2——这正是 CRD←CGD 迁移里菌株特异调制 m 要吸收的量级。

## 5. 交叉与富集：诚实的阴性 + 叙述性候选

- 超几何富集（总体=蛋白组可观测 4,888 基因）：高置信功能差异基因集 V（rank≥2，n=3,116）× CGD 响应活跃集 R1（top10%，K=489）重叠 269（期望 312，p≈1.0）；V × 菌株敏感集 R2 重叠 281（期望 304，p≈0.99）。**无富集**。
- 原因（必须明说）：近克隆对 0.15-0.4% 的差异散布全基因组，64% 的可观测蛋白基因都带功能/调控差异，V 集大到使富集检验无功效。"有序列差异"在该尺度下不是稀缺事件；机制叙事只能靠**效应等级 + 功能主题 + 响应强度**的叙述性排序，不能靠富集 p 值。
- 叙述性交叉主表 `cross_candidates.tsv`（score = 高置信效应等级 + R1/R2 成员 + 位点数）与按机制主题归组的 `theme_candidates.tsv`。

## 6. 五个机制故事（最值得讲的候选）

### 6.1 砷抗性：CRD 的 ARR 簇扩增（CNV → 表型，证据链最完整）

CRD 在 chr XVI 的 **ARR1（YPR199C，砷酸盐响应转录因子）/ARR2（YPR200C，砷酸盐还原酶）/ARR3（YPR201W，亚砷酸盐外排泵）各 2.5 拷贝，CGD 单拷贝**；ARR2 启动子另有 1 个 HQ 差异。1011 表型：CRD 在亚砷酸钠下生长 0.411 vs CGD 0.090（4.5×）。ARR 簇扩增是 1011 计划已发表的砷抗性主效 QTL——两株在这一经典 CNV 上基因型不同，是"近克隆 ≠ 表型等价"的最硬例证。若竞赛化合物中含砷类/重金属，CGD→CRD 的直接迁移会系统性高估 CRD 的抗性相关蛋白响应；β 收缩恰好限制了这类错配的损失。

### 6.2 PDR 药物外排网络：装备配置系统性不同

- **CGD 丢失/深度趋异四个外排泵**：QDR3（0/1，区内 56 个 HQ 差异位点，旁系比对特征）、PDR11（0/1，47 位点）、SNQ2（0/1，27 位点含 A463V/H814R/S629T/V823I）、QDR1（0/1）。
- **共有的泵上错义密集**：PDR5（主效 CHX/FLU 外排泵）13 个错义（E100Q、H113Y、H282Y、I348V、K689N、K940E、M1341V、S811T 等）+ PDR15（G235S/K1451T/V941I）+ YOR1（A847T/H112Y/V1429L）+ 主调控因子 **PDR1 D1063Y**（激活结构域区）。
- 表型呼应：CRD 保有全套泵却对 CHX（2×）、制霉菌素（3.7×）、咖啡因更敏感——说明差异不仅在"有无泵"，更在**调控层与泵的序列变体**（PDR5/PDR1 错义 + 各泵启动子差异）；方向不能简单从基因有无推断，叙事上如实保留这个张力。
- 竞赛侧：PDR11/QDR3/SNQ2 均在 CGD 响应活跃前 10%（mean|Δ| 0.30-0.71，max 3.2），且菌株敏感性中高（0.23-0.51）——这些蛋白在 CGD 中随化合物大幅波动，CRD 侧装备不同，响应不可直接平移。

### 6.3 细胞壁完整性轴：咖啡因敏感 3× 的分子底座

CRD 对咖啡因敏感 3×（咖啡因=细胞壁完整性/TOR 探针）。序列层：
- **GAS1**（β-1,3-葡聚糖延伸酶，细胞壁合成核心）：31 个 HQ **启动子**差异 + T11I 错义——调控序列被密集改写；DNABERT-2 窗口余弦距离 1.09×10⁻²，居全部目标窗第二（见 §7）。
- **GAS3/SCW10/UTR2**（细胞壁糖蛋白）移码；**CWP1/EXG2/ECM33** CGD 丢失；**BCK1（MAPKKK）/SLT2（MAPK）/RLM1（TF）** CWI 级联全链带 inframe indel/错义；FKS1（葡聚糖合酶）V601I/V1339A。
- 竞赛侧：GAS3（mean|Δ|=0.86，敏感性 0.67）、UTR2、BCK1 均在响应活跃+菌株敏感双前 10%。
故事线：两株细胞壁"材料-合成-信号"三层都有差异 → 任何扰动细胞壁/膜的化合物在两株中引发不同的下游蛋白组重构。

### 6.4 糖转运与碳源利用：HXT 簇缺失 + 碳源表型差

CGD 丢失 **HXT1**（0/0.5，区内 44 个 HQ 位点，DNABERT 窗口距离 0.10，含 1bp indel 致 BPE 重分段，见 §7 局限）且 **HXT5 带 30 个错义**；CRD 半乳糖利用 0.86 vs CGD 1.01、木糖 0.24 vs 0.42、核糖 0.37 vs 0.49。竞赛培养基为 YNB+CSM+2% 半乳糖——**碳源感知/摄取装备差异恰好落在竞赛实验条件的正下方**：半乳糖响应通路（GAL 调控+转运）在两株中的基线不同，是所有化合物响应的共享上游变量。

### 6.5 应激主调控与"缺失但仍有信号"的张力：MSN2、GRE1、rDNA

- **MSN2**（通用应激转录因子）位于 CGD 丢失区（YMR037C，CN 0/1）；其同源 MSN4 仅 1 个同义差异。若 CGD 的 MSN2 功能弱化，两株对环境扰动的全程序贯激活（ESR）强度不同——这与 CRD 在多胁迫下普遍更敏感的表型方向一致（MSN2 缺失株敏感）。
- **GRE1 Q82\***（CRD 提前终止 + 杂合缺失 0.5 拷贝）、**NCW2 Y156\***（CRD 提前终止 + 杂合缺失）：两个应激/细胞壁基因的剂量与完整性同时在 CRD 中受损；两者均在 CGD 响应活跃前 10%（0.70-0.90）。
- **"缺失但蛋白组有信号"**：IRC7（CN 0/1）在 CGD 中 mean|Δ|=1.26、MIH1 1.16、UBC5 0.68——质谱基于参考肽段库，深度趋异的同源产物仍可被部分定量，或这些区的 CN=0 主要是组装注释口径。叙事意义：**CN 矩阵的 0 不等于蛋白组管线的 0**，两数据层各有各的"缺失"定义，交叉使用时必须保留这一层不确定性。
- rDNA 拷贝 CGD 多 ~30%（RDN58 112.5/82.5 等）——翻译容量与生长基线差异，量级温和但全局。

## 7. 独立证据列：DNABERT-2 序列差异强度（可选增强，已完成）

对 18 个目标基因的差异最密 2001bp 窗口构建两株等位序列，DNABERT-2（117M，GPU）mean-pool embedding 余弦距离（`dnabert_window_scores.tsv`）：

- **管线验证**：5 个无差异对照窗距离 0–2.6×10⁻⁵（≈0，正确）；5 个仅同义对照窗 1.6×10⁻⁴–8.9×10⁻⁴。
- **目标窗**：PDR5 5.8×10⁻⁴（6 差异碱基，最低）< HPF1 1.7×10⁻³ < UTH1 2.1×10⁻³ < SNQ2 4.0×10⁻³ ≈ QDR3 4.0×10⁻³ < SCW10 4.3×10⁻³ < HXT5 5.6×10⁻³ < **GAS1 1.09×10⁻²** ≈ **ZRT3 1.24×10⁻²** ≪ HXT1 1.02×10⁻¹。
- 与 §6 的叙述性排序互洽：GAS1（31 启动子改写）、ZRT3、QDR3/SCW10/HXT5 的调控/功能序列差异强度独立于注释分类得到确认；PDR5 虽错义多但分散、窗口内仅 6 个 HQ 位点，序列层扰动小。
- **三点局限（如实标注）**：① 1bp indel 会引起 BPE tokenizer 重分段、下游全部 token 漂移（HXT1 的 0.10 主要是该伪影，不作功能解读）；② embedding 距离对变异在窗口中的位置敏感（无差异对照 RTR1 单 SNP 即 1.06×10⁻²），只能作定性证据；③ 无功能校准基线，距离≠调控效应大小。本证据列仅作叙事支撑，未入模。

## 8. 与 β=0.35 迁移的机制自洽性讨论

1. **距离-信号结构匹配**：两株 SNP 距离 ~0.2-0.4%（近到绝大多数化合物主效应可共享），但差异非随机地落在 PDR/细胞壁/离子稳态/糖转运——即"共享主干 + 通路级菌株调制"的结构。wsN8 的设计（路由预测 + β·m_CGD,chem，m=CGD 的菌株特异调制残差）正是这一结构的参数化：主效应来自共享化合物语义，菌株项只做小幅平移。
2. **量级匹配**：菌株背景效应 |中位差| ≈0.17 log2（q90 0.61）；m 本身是 pair_mean−化合物均值 的残差（已是小幅量），再乘 β=0.25-0.35 后落在 ~0.05-0.2 log2——与观测的菌株效应尺度同量级且偏保守，符合"有界赌注"定位（失败损失 ~−0.001 量级有界）。
3. **分布式差异 ⇒ 反对逐基因大改**：4,492 个基因带差异、无富集热点，不存在"修一个基因就对"的单点机制；任何逐基因大幅改写都缺乏证据支撑。β 全局收缩是与该证据结构相容的唯一温和选项。
4. **已知错配方向（供未来评审参考）**：若 test 化合物作用于砷/重金属、细胞壁、麦角固醇（制霉菌素类）、蛋白合成（CHX 类），CGD→CRD 迁移的系统性偏差最大（§6.1-6.3）；这些正是 β<1 提供保护的场景。
5. **可证伪性声明**：本迁移的 CRD 侧增益在 val/test 均不可诚实验证（CRD 仅 test；test 提交后无标签回流），wsN8 已声明其为"人工先验决策的有界赌注"。本报告为赌注提供机制叙事，不构成增益证据。
